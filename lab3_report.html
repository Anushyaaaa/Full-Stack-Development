7. Viva Voce Questions & Answers (2M Rubric Preparation)

Q1: What is the difference between Event Bubbling and Event Capturing?

Ans: Event Bubbling triggers the event on the deepest target element first and bubbles upwards through parent ancestors. Event Capturing (trickling) travels down from the root window towards the target. addEventListener(event, handler, useCapture) uses bubbling when the 3rd argument is false (default).

Q2: Why use e.preventDefault() in form submission?

Ans: By default, an HTML form submission triggers a browser HTTP GET/POST request that reloads or redirects the page. e.preventDefault() stops this standard browser behavior, enabling asynchronous client-side validation and feedback.

Q3: What is the difference between 'load' and 'DOMContentLoaded' events?

Ans: DOMContentLoaded fires as soon as the HTML document is fully parsed and DOM tree constructed, without waiting for stylesheets, images, and subframes. The load event fires later, once all resources (images, fonts, stylesheets) are completely downloaded.

Q4: What is the difference between 'mouseover'/'mouseout' and 'mouseenter'/'mouseleave'?

Ans: mouseover and mouseout bubble to parent elements and trigger when moving between child elements inside the card. mouseenter and mouseleave do not bubble.
