Core Source Code (JavaScript Event Listeners)

// 1. Window 'load' Event
window.addEventListener('load', function() {
    updateScreenWidth();
    setTimeout(() => alert("Welcome to CampusVibe — Christ University Event & Club Hub!"), 400);
});

// 2. Input 'input' Event (Live dynamic typing)
demoInput.addEventListener('input', function(e) {
    const val = e.target.value;
    typedValue.textContent = val || '(start typing above...)';
    charCount.textContent = val.length;
    logEvent('INPUT', `Search: "${val}"`);
});

// 3. Window 'resize' Event (Live browser width counter)
window.addEventListener('resize', function() {
    updateScreenWidth();
    logEvent('RESIZE', `${window.innerWidth}px x ${window.innerHeight}px`);
});

// 4 & 5. 'mouseover' & 'mouseout' Events (Feature / Event Cards)
document.querySelectorAll('.event-card, .club-card').forEach(card => {
    card.addEventListener('mouseover', () => card.classList.add('ring-2', 'ring-blue-500', '-translate-y-2'));
    card.addEventListener('mouseout', () => card.classList.remove('ring-2', 'ring-blue-500', '-translate-y-2'));
    card.addEventListener('dblclick', () => card.classList.toggle('bg-amber-50/50'));
});

// 6 & 7. 'focus' & 'blur' Events (Input active status)
demoInput.addEventListener('focus', () => fieldFocusStatus.textContent = 'State: Active (focus)');
demoInput.addEventListener('blur', () => fieldFocusStatus.textContent = 'State: Inactive (blur)');

// 8. Select 'change' Event (Dynamic domain preview)
domainTrackSelect.addEventListener('change', e => renderTrackPreview(e.target.value));

// 9. Window 'scroll' Event (Dynamic progress bar)
window.addEventListener('scroll', () => {
    const p = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
    document.getElementById('scrollProgressBar').style.width = p + '%';
});

// 10. 'contextmenu' Event (Custom right-click action palette)
demoSection.addEventListener('contextmenu', e => {
    e.preventDefault();
    openCustomMenu(e.pageX, e.pageY);
});

Reflections & Viva Voce Q&A

Key Learnings: Implementing event-driven programming on CampusVibe reinforced the asynchronous nature of the browser event loop. Separating visual presentation from dynamic behaviors via addEventListener guarantees clean, maintainable architecture. Using e.preventDefault() on form submissions and right-clicks illustrated how client-side applications can intercept default browser behaviors to deliver bespoke UX.

Q: Bubbling vs Capturing?

Bubbling propagates upwards from target to root; Capturing trickles down from root to target. Defaults to bubbling.

Q: Why preventDefault()?

Cancels native browser actions like form HTTP reloads or context menu openings, allowing custom JS execution.
