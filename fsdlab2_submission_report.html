Core Source Code (Vanilla JavaScript Event Listeners)

// 1. Window 'load' Event
window.addEventListener('load', () => {
    updateScreenWidth();
    setTimeout(() => alert("Welcome to CampusVibe — Christ University Event & Club Hub!"), 400);
});

// 2. Input 'input' Event (Live typing & card filtering)
searchInput.addEventListener('input', (e) => {
    const q = e.target.value;
    typedValue.textContent = q || '(start typing above...)';
    charCount.textContent = q.length;
    filterCards(q.toLowerCase());
});

// 3. Window 'resize' Event (Live width & breakpoint monitor)
window.addEventListener('resize', updateScreenWidth);

// 4 & 5. 'mouseover' & 'mouseout' Events (Hover elevation & glow)
document.querySelectorAll('.interactive-card').forEach(card => {
    card.addEventListener('mouseover', () => card.classList.add('ring-2', 'ring-brand-500', '-translate-y-2'));
    card.addEventListener('mouseout', () => card.classList.remove('ring-2', 'ring-brand-500', '-translate-y-2'));
    card.addEventListener('dblclick', () => card.classList.toggle('bookmarked-card'));
});

// 6 & 7. 'focus' & 'blur' Events (Field focus state)
searchInput.addEventListener('focus', () => fieldFocusStatus.textContent = 'State: Active');
searchInput.addEventListener('blur', () => fieldFocusStatus.textContent = 'State: Inactive');

// 8. Select 'change' Event (Domain track switcher)
eventTrackSelect.addEventListener('change', (e) => renderTrackPreview(e.target.value));

// 9. Form 'submit' Event (RSVP validation & preventDefault)
rsvpForm.addEventListener('submit', (e) => {
    e.preventDefault();
    if (validateRSVP()) showConfirmation();
});

// 11. Window 'scroll' Event (0% - 100% progress indicator)
window.addEventListener('scroll', () => {
    const docHeight = document.documentElement.scrollHeight - window.innerHeight;
    const progress = docHeight > 0 ? (window.scrollY / docHeight) * 100 : 0;
    scrollBar.style.width = Math.min(100, Math.max(0, progress)) + '%';
});

// 12. Area 'contextmenu' Event (Custom right-click menu with coordinates)
contextMenuArea.addEventListener('contextmenu', (e) => {
    e.preventDefault();
    openCustomMenu(e.pageX, e.pageY);
});

Reflections & Viva Voce Q&A

Reflections & Learnings: Implementing the 12 events on CampusVibe reinforced the architecture of the browser's asynchronous event loop. Modern DOM event listeners using addEventListener() ensure complete separation of concerns between markup and logic. Custom event interception via event.preventDefault() was instrumental in validating the RSVP form without page reloads and implementing the coordinate-positioned custom context menu.

Q: Event Bubbling vs Event Capturing?

In Capturing, the event travels from window down to target. In Bubbling (standard default), the event executes on the target element first and bubbles upwards to ancestors.

Q: Why use event.preventDefault()?

Stops native browser behaviors like form HTTP POST page reloads or opening the OS context menu, enabling client-side validation and custom interactions.
