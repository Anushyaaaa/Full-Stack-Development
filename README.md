# College Event & Club Management Platform — Campusly

A modern, visually stunning, standalone landing page for the **College Event & Club Management Platform ("Campusly")**, built purely with **HTML5 & CSS3** (zero JavaScript, standalone single-file architecture).

---

## 🌟 Overview

**Campusly** is an intelligent university technology platform designed to streamline campus life. It allows students to discover college events, explore and join student organizations, track registrations, and connect across campus communities.

---

## 🚀 Features

- **Pure HTML5 & CSS3**: Built with zero JavaScript (`<script>` tags, libraries, or frameworks) while retaining high-level interactivity and modern aesthetics.
- **Glassmorphism & Neon Aesthetics**: Deep void navy backdrop (`#060713`, `#0a0c20`), electric blue, violet, and cyan glowing accents, and `backdrop-filter: blur()` glass cards.
- **Hero Showcase**:
  - Live status indicator: `"SMART CAMPUS • CONNECT • COLLABORATE • CREATE"`.
  - Multi-stop gradient typography.
  - Interactive 3D glass dashboard with live campus photo and attendee avatar stack.
  - Floating satellite badges: *Upcoming Event (TechFest 2026)*, *Club Spotlight (AI & Robotics)*, and *Event Registration (87% Filled)*.
- **Key Statistics Strip**: 50+ Active Clubs, 120+ Annual Events, 8K+ Student Members, 95% Student Engagement.
- **Campus Ecosystem (6 Feature Cards)**: Event Discovery, Club Management, Smart Registration, Student Community, Event Notifications, and Campus Analytics.
- **Upcoming Events Preview**: Featured cards for TechFest 2026, Cultural Carnival, and AI & Robotics Summit with zoom-on-hover effects.
- **Club Directory Showcase**: Spotlight cards for AI & Robotics Club, Coding Club, Photography Club, and Cultural Club.
- **Split Community Section**: Highlights peer collaboration, live project stats, and cross-disciplinary networking.
- **How It Works Timeline**: 4-step progressive workflow with glowing numbered nodes and connecting line.
- **Student & Coordinator Testimonials**: Verified review cards with 5-star ratings and profile avatars.
- **Pure CSS Mobile Navigation**: Hamburger menu toggle built using CSS checkbox hack (`#mobile-nav-toggle`).
- **Fully Responsive**: Optimized for desktop (1440px, 1200px), tablets (768px), and mobile viewports (480px, 360px).
- **Accessible**: Semantic HTML structure with `prefers-reduced-motion` support.

---

## 💻 How to Run

Since the project is built as a standalone HTML5/CSS3 application with all styles embedded:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Anushyaaaa/Full-Stack-Development.git
   ```
2. Open either `index.html` or `fsdlab1.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari).
3. No build tools, Node.js, or local servers are required!
